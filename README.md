# Course Material → Quiz Generator (Local LLM)

A Streamlit tool that reads your course material (PDF or DOCX) and uses a
**locally-running LLM (via Ollama)** to draft a multiple-choice quiz —
questions, plausible wrong options, a suggested correct answer, and a
one-line explanation for each. You review and edit everything, then
export a completely separate, self-contained `quiz_app.py` + `README.md`
you can hand to students or push to GitHub.

**Nothing leaves your laptop.** The model runs locally through Ollama;
no API keys, no internet calls except to `localhost`.

## What you get

Two different apps, for two different purposes:

| File | Purpose | Needs Ollama? |
|---|---|---|
| `app.py` (this one) | The builder tool — upload material, generate + edit questions | Yes |
| `quiz_app.py` (generated by the builder, per document) | The actual quiz students take | No — fully self-contained |

## 1. Install Ollama and pull a model

Download Ollama from [ollama.com](https://ollama.com), then in a terminal:

```bash
ollama pull llama3.2:1b
# optional, better quality but slower on CPU:
ollama pull qwen3:4b
```

Start the Ollama server (it may already be running in the background
after install):

```bash
ollama serve
```

### Which model should I use on an 8GB / Core i5 laptop?

- **`llama3.2:1b` (default, recommended)** — about 1.3GB, fast on CPU,
  leaves headroom for Streamlit, your browser, VS Code, etc. Good
  enough for straightforward factual course material.
- **`qwen3:4b`** — noticeably better question quality and phrasing,
  but slower per chunk on CPU-only inference and uses more RAM. Use it
  when you have few other apps open and can wait a bit longer, or for
  material where question quality really matters.

If generation feels slow or your laptop starts swapping: close other
heavy apps, switch to `llama3.2:1b`, or reduce the number of questions
requested (fewer questions = fewer model calls = faster).

## 2. Install Python dependencies

```bash
pip install -r requirements.txt
```

## 3. Run the builder

```bash
streamlit run app.py
```

Open the local URL Streamlit prints (usually `http://localhost:8501`).

## 4. Use it

1. Upload a PDF or DOCX of your course material.
2. In the sidebar, pick your model, how many questions, and how many
   options per question.
3. Click **Generate Quiz**. This can take anywhere from ~30 seconds to
   several minutes depending on document length and model size — it's
   all running on your CPU.
4. Review the drafted questions. Edit wording, swap options, change
   the marked correct answer, or remove a question entirely.
5. Click one of the **Export** buttons to download `quiz_app.py`,
   `README.md`, or both as a zip.

## 5. Run or share the generated quiz

The exported `quiz_app.py` is completely standalone:

```bash
pip install streamlit
streamlit run quiz_app.py
```

To share it: copy `quiz_app.py` + its `README.md` into a new (or
existing) GitHub repo, and optionally deploy it for free on
[Streamlit Community Cloud](https://share.streamlit.io) with the main
file path set to `quiz_app.py`.

## Notes / troubleshooting

- **"Could not connect to Ollama"** — make sure `ollama serve` is
  running, and that the host in the sidebar matches (default
  `http://localhost:11434`).
- **Scanned/image-only PDFs** won't extract usable text — this tool
  only handles text-based PDFs and DOCX files. For scanned documents,
  run OCR first (e.g. with a tool like `ocrmypdf`) before uploading.
- **Always review AI-drafted questions and answers before giving them
  to students.** The model is drafting from your material, but it can
  still misstate something or pick an implausible wrong option — the
  review/edit step in the builder exists for exactly this reason.
- Long documents are automatically split into sections, and questions
  are spread proportionally across them so the quiz covers the whole
  document rather than just the first few pages.
