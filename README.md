# Course Material → Quiz Generator (Ollama Cloud)

A Streamlit tool that reads your course material (PDF or DOCX) and uses
a model on **Ollama Cloud** to draft a multiple-choice quiz — questions,
plausible wrong options, a suggested correct answer, and a one-line
explanation for each. You review and edit everything, then export a
completely separate, self-contained `quiz_app.py` + `README.md` you can
hand to students or push to GitHub.

**This version does not run any model on your machine.** Generation
happens on Ollama's cloud infrastructure over HTTPS — nothing to
install beyond Python packages, and your laptop doesn't need to stay on
for a deployed version of this app to keep working.

## What you get

| File | Purpose | Needs Ollama Cloud? |
|---|---|---|
| `app.py` (this one) | The builder tool — upload material, generate + edit questions | Yes, at generation time |
| `quiz_app.py` (generated by the builder, per document) | The actual quiz students take | No — fully self-contained, questions/answers are baked in |

## 1. Get an Ollama Cloud API key (free tier available)

1. Sign up / sign in at [ollama.com](https://ollama.com).
2. Create an API key at [ollama.com/settings/keys](https://ollama.com/settings/keys).
3. Either:
   - **Set it as an environment variable** before launching (recommended
     — it'll pre-fill the sidebar automatically):
     ```bash
     export OLLAMA_API_KEY=your_key_here        # Mac/Linux
     setx OLLAMA_API_KEY "your_key_here"         # Windows (open a new terminal after)
     ```
   - **Or** just paste it into the "Ollama API key" field in the app's
     sidebar each time you run it.

Ollama's free plan has usage limits that reset periodically; heavier
use requires a paid plan (Pro/Max) — see [ollama.com/pricing](https://ollama.com/pricing).

## 2. Install Python dependencies

```bash
pip install -r requirements.txt
```

## 3. Run the builder

```bash
streamlit run app.py
```

Open the local URL Streamlit prints (usually `http://localhost:8501`).

## 4. Use it

1. Upload a PDF or DOCX of your course material.
2. In the sidebar: pick a model (`gpt-oss:20b` is a good low-usage
   default on the free plan), enter/confirm your API key, and choose
   how many questions and options per question you want.
3. Click **Generate Quiz**. Since this runs on Ollama's cloud hardware
   rather than your CPU, it's typically much faster than local
   generation was.
4. Review the drafted questions. Edit wording, swap options, change
   the marked correct answer, or remove a question entirely.
5. Export `quiz_app.py`, `README.md`, `questions.json`, or all three as
   a zip.

## 5. Run or share the generated quiz

The exported `quiz_app.py` is completely standalone — it does **not**
call Ollama Cloud or any other service:

```bash
pip install streamlit
streamlit run quiz_app.py
```

To share it: copy `quiz_app.py` + its `README.md` into a new (or
existing) GitHub repo, and optionally deploy it for free on
[Streamlit Community Cloud](https://share.streamlit.io) with the main
file path set to `quiz_app.py` — no API key or secrets needed for the
*generated* quiz app, since it doesn't call any model at runtime.

## Notes / troubleshooting

- **"Ollama Cloud rejected the API key (401)"** — double-check the key
  in the sidebar matches what's shown at
  [ollama.com/settings/keys](https://ollama.com/settings/keys), and
  that it hasn't been revoked.
- **"Rate/usage limit hit (429)"** — you've hit your plan's usage
  limit. Wait for it to reset, reduce the number of questions
  requested, or upgrade at [ollama.com/pricing](https://ollama.com/pricing).
- **Model tag not found** — Ollama's cloud catalog changes over time.
  If a model in the dropdown stops working, use "Custom model tag..."
  in the sidebar and check currently available tags for your account.
- **Scanned/image-only PDFs** won't extract usable text — this tool
  only handles text-based PDFs and DOCX files.
- **Always review AI-drafted questions and answers before giving them
  to students.** The model drafts from your material, but it can still
  misstate something or pick an implausible wrong option — the
  review/edit step in the builder exists for exactly this reason.
- Because generation now runs on Ollama's servers, uploaded course
  material text is sent to Ollama Cloud as part of each request. If
  your material is sensitive, keep that in mind (see Ollama's privacy
  policy) — this trade-off is what you get in exchange for not needing
  local compute.
